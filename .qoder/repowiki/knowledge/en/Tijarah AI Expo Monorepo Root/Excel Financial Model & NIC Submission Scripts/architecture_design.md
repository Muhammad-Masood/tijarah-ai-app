Flat collection of single-purpose CLI utilities with no shared library — each `.py` or `.js` file is independently executable via `python <script>` or `node reset-project.js`. All Excel manipulation uses `openpyxl` against two hard-coded input paths: a local downloaded copy under `c:\Users\dossani\Downloads\...` and a project-local copy under `docs\NIC-ACCELERATION-COHORT-4-Application-Deliverables-Tijarah-AI.xlsx`. Scripts fall into four roles: (1) inspection/audit (`inspect_excel.py`, `inspect_financial.py`, `audit_excel.py`, `read_investment_rows.py`, `read_key_numbers.py`, `read_product_listed.py`, `list_merged.py`, `check_cells.py`) which dump sheet contents to stdout or `*_output.txt`; (2) mutation/update (`update_free_tier_model.py`, `fix_nic_excel.py`, `fix_financial_formatting.py`) which compute Y1/Y2 MRR, COGS, gross profit, margins, and write values back into named sheets (`Financial Model`, `Information Memorandum`, `Business Plan`, `Lean Business Canvas`, `Pre-Investment CapTable`, `Product listed`, `Customer Persona Canvas`); (3) verification (`verify_financial_model.py`) which re-derives GP from MRR minus AI/hosting/legal costs and flags mismatches; (4) project scaffolding (`reset-project.js`) which moves/deletes `src` and `scripts` directories and writes fresh Expo app files. Cross-cutting helpers include a `set_cell(ws, coord, value)` pattern that unmerges merged cells before writing, and shared constants for FX rate (280 PKR/USD), AI inference cost ($4.90/paid merchant/month), hosting ($70/mo), and platform fee (month-1 $143).
