The repository is organized as a flat workspace with two independent concerns: `src/` implements the cross-platform Expo Router application (file-based routing under `src/app/`) and `scripts/` contains Python and Node utilities that inspect and update the NIC Acceleration Cohort Excel workbook. There is no runtime or build-time import coupling between them; they share only the root workspace via `package.json` scripts, `tsconfig.json` path aliases, `eslint.config.js` rules, and `.env` variables consumed by both sides. `app.json` declares the Expo manifest used at runtime, while top-level config files (`tsconfig.json`, `eslint.config.js`, `package.json`) provide the shared toolchain surface that each child consumes independently.
